知识

wiki 是原文之上的一层：模型把导入的资料编译成条目（结论先行 + 每条结论带原文出处）， 存成 .glassbox/kb/wiki/**.md 普通 Markdown 文件——可以用编辑器直接改、可以 git 管。 和资料库的关系是「原文 → 编译 → 条目」，原文永久保留，条目随时可以重新编译。

生成后会过一道不调模型的溯源校验：条目里出现的每个数字和标识符，必须能在它引用的原文块里 一字不差地找到，找不到就标「未通过校验」——LLM 编译知识最大的风险是编造，这道闸是机械的。 生成规则写在 .glassbox/kb/wiki/AGENTS.md（首次生成时从仓库模板复制），改它就改下次生成结果。

粘贴文本或选择 .md / .txt 文件导入。导入后按 Markdown 标题切块建索引， 之后你在对话里提问时会自动检索并注入相关段落，注入了哪几段可以在对话页右侧「资料库」面板里看到。 原文保存在 .glassbox/kb/raw/，同名重复导入 = 版本递增、旧分块整体替换。

资料库是整个工作区共用的：导入一次，之后所有会话（包括新建的、分叉出来的、以及重启进程之后的） 都能检索到它，不属于某一次对话。它和「记忆」的区别是——资料库是你主动喂进来的原始资料， 记忆是从对话里自动蒸馏出来的零碎结论。

除了自动注入，模型还能主动调 kb_search（换关键词再查）、kb_read（读某篇/某章全文）、 kb_answer（只按资料作答并附来源）。导入时会顺手扫一遍疑似密钥和疑似重复，只提示不拦； 每篇的 v? 按钮能看历史版本、和当前版本逐行对比、必要时回滚； 30~60 天没更新标「待复核」，超过 60 天标「已过期」。 点「蒸馏」会让模型给每篇资料生成一段摘要和一串别名：它只参与检索打分、永远不会被注入， 作用是问法和原文用词不一致时（「获取锁超时」vs 原文「抢锁失败」）还能把真正写着答案的段落捞出来。
