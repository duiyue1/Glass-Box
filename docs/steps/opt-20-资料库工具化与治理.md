# 优化 20 · 资料库工具化 + 治理（第三、四批）

接着 opt-19 往下做，把 AI-Ku 那边的两块能力搬过来：
**MCP 文档工具组**（`doc_search` / `doc_content` / `doc_rag`）和
**治理 Agent + 合规 Agent**（版本对比、时效巡检、重复合并、敏感信息过滤）。

## 第三批 · 工具化

之前资料库只有「被动注入」：每回合按提问检索几段塞进上下文。够用，但模型做不到三件事——
换个关键词再查一次、翻到某一章读全文、明确说「资料库里没有这个」。
新增 `src/plugins/kbPlugin.ts`，三个只读工具（safe，不触发审批）：

- **`kb_search(query, topK≤10)`** ≈ `doc_search`。走同一套 BM25 + 整形。
  查不到时返回的是**一句明确的话**（「资料库里没有和「X」相关的内容（共 N 篇）…告诉用户资料里没有」），
  不是空串——空串等于放任模型自己编。
- **`kb_read(doc?, section?, part?)`** ≈ `doc_content`。不给 `doc` 就列出所有文档 + 章节清单
  （模型先看有什么再决定读哪篇）；给了 `doc` 可用 `section` 限定章节、`part` 翻页（单次 6000 字）。
  文档/章节找不到时把**现有选项**一起返回，模型能自己纠正参数。
- **`kb_answer(question)`** ≈ `doc_rag`。检索 → 用「只根据【资料】回答，没写就说没写，末尾列来源」
  的 system 提示再问一次模型 → 返回答案 + 来源清单。
  没传 `llm` 时**不注册**这个工具（比注册一个必然失败的工具好）。

被动注入没有被替换掉，两条路并存：注入负责「不用问就顺手带上」，工具负责「不够时自己去挖」。

## 第四批 · 治理

### 版本历史 + 回滚

之前同名导入直接覆盖 `raw/<id>.md`，上一版内容就没了。现在覆盖前先存一份到
`raw/history/<id>.v<上一版>.md`：

- `versions(id)` 列出当前版本 + history 里留下的旧版本（旧版本时间用文件 mtime，只有当前版本有准确 ts）
- `rawVersion(id, version)` 读任一版本原文
- `rollback(id, version)` **不是把版本号退回去**，而是把旧内容当成一次新导入（v2 回滚到 v1 → 生成 v3）。
  历史只增不减，回滚这个动作本身也留痕
- `remove(id)` 连 history 一起清，否则删完再同名导入会看到「祖先版本」

### 时效巡检

文档行显示相对时间（`3 天前` / `2 个月前`），超过 90 天标「久未更新」。
只提示、不动数据——过期文档被当权威注入是真实风险，但判断该不该更新是人的事。

### 重复检测

`duplicatesOf(text, {excludeId, threshold=0.6})`：词集合 Jaccard + MD5 全等判断。
导入后立刻拿真实 `doc.id` 排除自己再比一遍，命中就在面板上提示「考虑合并或归档其中一篇」。
不阻止入库。两篇高度重合的资料会互相挤占检索预算，这是它真正的代价。

### 敏感信息扫描（`src/kb/secrets.ts`）

动机很直接：**资料库的内容每回合都可能被拼进请求发给外部模型 API**。
一份带 API key 的配置文档导进来，等于主动把密钥送出去。

9 条规则（OpenAI `sk-`、AWS `AKIA/ASIA`、GitHub `gh?_`、Slack `xox?-`、Google `AIza`、
JWT、私钥头、`key=value` 形式、带密码的连接串），占位符（`your-api-key-here` / `<TOKEN>` /
`${VAULT_SECRET}` / `xxxx`）过滤掉。报告里**只回显打码片段**（头尾各 3 字符），绝不回显完整密钥。
同样是只提示不拦。

### 重新索引

改了 chunker 的 `maxTokens/overlap` 之后，老文档不会自动跟着变。
`reindex()` 从 `raw/` 按当前参数全部重切，**版本号不变**（内容没改，只是切法变了），
读不到原文的文档在返回值里报出来而不是静默跳过。

### 注入正文留档

`kb.injected` 事件加 `content` 字段 = 真正拼进提示词的那段正文原文。
之前只记了标题/分数/token，事后没法一字不差地复核「到底喂了什么」。
`GB_KB_LOG_TEXT=0` 可关（日志体积敏感时）。

## 接口与面板

新增/改动的端点：

- `GET /kb/versions?id` 版本列表
- `GET /kb/raw?id&version=N` 读指定版本（不带 `version` 还是读当前版本）
- `POST /kb/rollback {id, version}` 回滚
- `POST /kb/reindex` 全量重切
- `POST /kb/import` 返回值加 `warnings: { secrets, duplicates }`

资料库页：每篇多一个 `v?` 按钮（展开版本列表，可查看原文 / 回滚），页面级「重新索引」按钮，
导入后在告警框里显示疑似密钥与疑似重复，文档行显示相对时间与「久未更新」标记。

## 验证

**单测**：170 → **186 全绿**，新增 16 条：版本归档与 `versions` 顺序、`rollback` 生成新版本且索引跟着回滚、
`rollback` 的错误分支、`reindex` 保持版本号 / 报告缺失原文、`duplicatesOf` 全等与排除自己、
`remove` 清历史、`scanSecrets` 报行号且不回显原文 / 不报占位符、
`kb_search` 命中与「查不到要直说」、`kb_read` 列清单 / 限定章节 / 参数错误给选项、
`kb_answer` 只在有 llm 时注册 / 带来源 / 检索不到时不问模型、三个工具都不触发审批。

`tsc --noEmit --strict` 无错。

**真实模型实跑**（gpt-5.5，你的 `.env` 原样，用的是你已经导入的《调度服务 SDD》）：

```
你> …用 kb_read 把分布式锁那一章读出来再回答，不要凭印象。
   [工具] kb_read({"doc":"调度服务 SDD","section":"分布式锁"})
   [工具] 结果: 《调度服务 SDD》v1 · 章节匹配「分布式锁」…
AI> （原样引用了整节内容，包括 Lua 校验 nonce、三个被否决的方案、四个监控指标）

你> 用 kb_answer 严格按资料库回答…另外再用 kb_search 查一下有没有讲「熔断」，没有就直说没有。
   [工具] kb_answer({"question":"调度服务的锁租约多久、续租周期多久？"})
   [工具] 结果: 锁租约是 30 秒，续租周期是 10 秒。来源：调度服务 SDD > 3. 分布式锁
   [工具] kb_search({"query":"熔断","topK":5})
   [工具] 结果: 资料库里没有和「熔断」相关的内容（共 2 篇资料）…
AI> 租约 30 秒 / 续租 10 秒（附来源）；资料库里没有和「熔断」相关的内容。
```

两个都是模型**自己选的工具**，第二个还是一次并行调用（`kb_answer` + `kb_search`）。
「查不到」这条路径也走通了——模型照实说没有，没有编。

**治理端点实测**（临时工作区起 web，`curl` 打完就清掉）：

```
导入带 sk- 的文档     → warnings.secrets: [{OpenAI 风格密钥, line 5, "sk-************vwx"}]
换标题导同一份内容    → warnings.duplicates: [{部署手册, similarity 0.93}]
同名导入第二版        → versions: [v2(current), v1]
GET raw?version=1     → 拿回 v1 原文
POST rollback v1       → v3，source="rollback:v1"，内容 = v1
POST reindex           → {docs:2, chunks:2, missing:[]}
```

## 已知缺口

- **面板上的版本/回滚/告警/重新索引这几个按钮，我只做了语法与 DOM 引用层面的校验（`test/ui.test.ts`），
  没有在浏览器里点过**——需要你重启 `npm run web` 后自己试一下
- history 里只有「加上归档之后」的版本；opt-20 之前导入的文档，旧版本已经不存在了
- `kb_read` 限定章节时，返回内容开头会带上一小段前一块的重叠上文（chunker 的设计如此），
  不是章节边界算错了
- 重复检测是词集合 Jaccard，改写过的同义文档（换了措辞的同一份规范）测不出来
- 敏感信息扫描是正则，只能拦「长得像密钥」的东西；业务侧的个人信息（身份证、手机号）没做
- 时效巡检只按 90 天一刀切，没有「按文档类型给不同保质期」
- Web 端点仍然**没有任何鉴权**（含新增这几个写操作）。只绑本地回环，但任意网页都能对
  `127.0.0.1:7777` 发跨站 POST——`/kb/rollback`、`/kb/delete`、`/ask` 都能被别人的页面触发。
  这是我一直挂在这儿的头号建议
